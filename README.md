# Josh Van Tassel
**Distribution Optimization Specialist · Graco Inc.**

I work at the intersection of distribution operations and enterprise systems:
translating how freight actually moves into the requirements, data, and tools
that make it move better.

## Focus areas
- **Logistics systems integration:** ERP-to-TMS workflows, carrier configuration, routing, and shipping documentation
- **Operational reporting & analytics:** SQL-based analysis and dashboards that give operations, customer service, and leadership reliable visibility
- **EDI & trading-partner data:** X12 order and shipment data, carrier and ship-method mapping
- **Compliance-driven shipping:** dangerous goods, export documentation, and the controls that keep shipments moving
- **Process design:** requirements, workflow design, and structured documentation for cross-functional change

## How I work
- Start from the operational problem and real examples, not the tool
- Separate confirmed facts from assumptions, and document decisions
- Build reusable artifacts (templates, checklists, data models) instead of one-off fixes
- Use AI-assisted tooling with clear guardrails around data and systems
